# Key derivation

BIP39 recovery words, BIP32 derivation, BIP86 Taproot keys, and the `KeyStore`
protocol a signer reads its secret through. The Apple Keychain implementation of
that protocol stays in WalletCore; the [topic guide](../../WalletCore/Keys/README.md)
covers both, and their tests.
