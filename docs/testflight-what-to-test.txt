Tor is gone, and the wallet key now asks for you itself

0.7.2 removes the opt-in Tor client that 0.6 through 0.7.0 embedded, and puts the wallet's key behind the phone's own passcode or Face ID check inside the Keychain, not only the app's. The app now always connects directly, the way it did with Tor off. Nothing else in the interface has moved.

The wallet key check

Reveal the recovery phrase, send a payment, or export a backup with the phrase: you should see one passcode or Face ID prompt, not two. An existing wallet opens with no prompt and nothing changes; the stronger protection is put on quietly the first time this version opens the wallet. A prompt worded "Unlock this wallet's protected key" means the app's own check and the Keychain's did not join up: report it, with what you were doing and whether Face ID or the passcode was used.

If you had Tor on

The first launch shows one alert, "Tor is no longer part of Winnow", and the app then connects directly. The alert appears once. If you never turned Tor on, there is no alert.

Advanced settings

The Tor section is gone, and so is the "Tor open-source licenses" row under About. "Refresh peer list" reports the observed date and a number of candidates. "Reconnect peers", "Reset and shuffle peers" and the manual peers still behave as in 0.7.0.

Explorer lookups

The funding-address consent now says only that the explorer receives the transaction ID and your IP address. The external-browser warning says the browser shares its IP address with the site.

Everything else

Beginner mode, Send, Receive, shared savings, backups, signing with a second device and the iPad and Mac builds should behave exactly as in 0.7.0. Anything that differs is a regression.
