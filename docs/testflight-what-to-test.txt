The device security check is gone

It was evidence tooling: v0.5.3 captured the locked-Keychain refusal, the hidden app-switcher card, and the resident-memory readings the release gate needed, and those are banked in the public security register. With the evidence in, the instrument leaves the app — Settings should now go straight from the peers list to About. If you still see the check, you are on v0.5.3.

Everything else

Normal use: receive, send, vault flows, backup. Vault coins mined directly to a vault address still show "matures in N blocks" and refuse early spending. Nothing else should feel different — if it does, that is worth a report.
