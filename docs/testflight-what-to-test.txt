Tor is gone; everything else should be unchanged

0.7.1 removes the opt-in Tor client that 0.6 through 0.7.0 embedded. The app now always connects directly, the way it did with Tor off. Nothing else in the interface has moved.

If you had Tor on

The first launch shows one alert, "Tor is no longer part of Winnow", and the app then connects directly. The alert appears once. If you never turned Tor on, there is no alert.

Advanced settings

The Tor section is gone, and so is the "Tor open-source licenses" row under About. "Refresh peer list" reports the observed date and a number of candidates. "Reconnect peers", "Reset and shuffle peers" and the manual peers still behave as in 0.7.0.

Explorer lookups

The funding-address consent now says only that the explorer receives the transaction ID and your IP address. The external-browser warning says the browser shares its IP address with the site.

Everything else

Beginner mode, Send, Receive, shared savings, backups, signing with a second device and the iPad and Mac builds should behave exactly as in 0.7.0. Anything that differs is a regression.
