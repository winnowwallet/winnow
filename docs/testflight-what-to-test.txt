One screen for beginners

Beginner mode is now a single screen, and Advanced mode is the three-tab interface you had before. Nothing is removed; it is moved. Update in place over 0.6.4: your saved recipients, shared accounts and settings should all still be there.

The one screen

With Advanced mode off you should see: your balance with one line under it (Up to date, Syncing…, or a connection problem with Retry), a Signet tag if this is a signet wallet, Receive and Send buttons, Activity, shared savings only if you have some, one row "Save with someone…", and "Back up wallet". There is no tab bar and no Settings. Pull down to refresh. Activity rows say Confirmed, Pending or Replaced, with no block numbers or fees; open a payment and the address and transaction ID are folded under "Address" and "Transaction ID".

Send and Receive

Send opens as a sheet: address or saved recipient, amount, Review, Send. After sending, the receipt stays open until you tap Done, and the payment appears in Activity as Pending, then Confirmed. Receive is unchanged, including the unconfirmed-payment notice. "Send to" on a received payment and Send from a shared account both open the same sheet.

Shared savings

"Save with someone…" offers two choices: start savings with people you have added, or join savings someone shared with you. Each opens the same flow as before. Custom rules and the second signing device are in Advanced mode.

Backup

"Back up wallet" opens the backup file and recovery-words controls that used to be in Settings. The words must still hide while the screen is being recorded, and must clear when you leave the app.

The switch

Tap Advanced in the corner: the app asks first, then changes to the three tabs. Settings no longer has an Advanced mode row; Simple, on the Wallet tab, brings the one screen back. Anything you set in Advanced mode — Tor, manual peers, a custom explorer, chain verification — stays in effect in beginner mode. If you had Advanced mode on in 0.6.4, you start in Advanced mode.

Everything else

iPhone, iPad and the Mac build; the Advanced tabs, signing journeys, peers, Tor and the explorer should behave as in 0.6.4.
