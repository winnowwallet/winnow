Winnow 0.7.10: Tor and I2P peers through your own Tailscale gateways

Winnow does not include Tor or I2P. This build can route Bitcoin peer connections through Tor and I2P SOCKS gateways that you run on your own Tailscale network. Setup: https://github.com/winnowwallet/winnow/blob/main/docs/peer-gateways.md

Gateway routing

With Tailscale connected on the iPhone and gateways named winnow-tor-gateway (port 9050) and winnow-i2p-gateway (port 4447) on the same tailnet, open Advanced → Settings → Peer networks. Automatic, the default, should show Active Tor gateway and Active I2P gateway. Without Tailscale, Automatic should fall back to ordinary peers with no error.

Choose Manual, enable only Tor peers, enter the Tor gateway, and tap Apply routing. Connected peers should become .onion addresses. Repeat with only I2P peers: tap Refresh peer list and check that it succeeds (it downloads from the I2P mirror), then check for .b32.i2p peers. Turn Tailscale off while in a Tor-only or I2P-only mode: the wallet should stop connecting rather than use ordinary peers. Choose Automatic again to restore ordinary peers.

Connections

Check a fresh install and an existing wallet: both should connect and sync. In Advanced settings, use "Refresh peer list" and check the reported observation date and candidate count. Report any connection failure with the network, routing mode and app version.

Payments and shared accounts

On signet, receive and send an ordinary payment, then receive and send with a MuSig2 shared account and a script-path 2-of-3 account. Check the recipient, amount, fee, approvals, and confirmed balance.

Upgrading from an older version

Check that your accounts, transaction history, backups and saved settings remain available after the update.

Report bugs publicly at https://github.com/winnowwallet/winnow/issues. Include the app version, device, network, and steps to reproduce. Never include recovery words, private keys, or wallet backup files.
