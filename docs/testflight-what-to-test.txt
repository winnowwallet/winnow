Winnow 0.7.9: automatic complete iCloud recovery and mainnet startup

Peer-list updates now require a valid signature from the pinned census publisher. The bundled address list has been removed. Mainnet automatically refreshes a missing or expired signed census alongside DNS discovery and remembered peers. Older unsigned or expired census caches are ignored.

Mainnet now connects to responsive peers without waiting for unrelated discovery attempts. A disconnected peer no longer leaves a response request waiting for its 30-second timeout. Check fresh startup, returning to the app, and repeated syncs.

iCloud recovery

Using a disposable signet wallet, create the wallet without enabling backup or completing a recovery-word checklist. Check the saved date after the automatic upload. On a second device with the same Apple Account and iCloud Keychain enabled, choose Restore from iCloud. Verify addresses, history, shared accounts, saved people, labels and the ability to sign. Confirm automatic backup resumes on the replacement device. Check that Advanced opt-out persists across mode changes and restart. Check a missing Keychain key, offline recovery and cancellation. Keep the original wallet and manual backup until verified; never erase your only funded wallet for this test.

Connections

Check a fresh install and an existing wallet: both should connect and sync without a bundled peer list. In Advanced settings, use "Refresh peer list" and check the reported observation date and candidate count. Reconnect peers and check that the wallet resumes syncing. Report any connection failure with the network and app version.

Payments and shared accounts

On signet, receive and send an ordinary payment, then receive and send with a MuSig2 shared account and a script-path 2-of-3 account. Check the recipient, amount, fee, approvals, and confirmed balance. The automated iPhone journey covers these payments with Bitcoin Core cosigners; report any difference you see in normal use.

Upgrading from an older version

Check that your accounts, transaction history, and backups remain available. Reveal the recovery phrase, send a payment, or export a backup with the phrase and check the passcode or Face ID prompt. Winnow now connects directly: users who previously enabled Tor should see the removal notice once.

Report bugs publicly at https://github.com/winnowwallet/winnow/issues. Include the app version, device, network, and steps to reproduce. Never include recovery words, private keys, or wallet backup files.
