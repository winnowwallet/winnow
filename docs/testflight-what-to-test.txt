Security review fixes

This build carries the fixes from the September security review. Most of them are below the surface; these are the places where you can see them.

Update in place first: install this build over 0.6.3 with saved recipients and at least one shared account. Everything should still be there after the first launch. (The files are sealed on that launch; a missing person or account would be a defect, not the design.)

Key fingerprints

Open a shared account. The Co-owners section now lists every approving key with a fingerprint like "ab12 cd34": the person it belongs to, "you", or, in red, a key that is not one of your people. Open Receive → Share my card on each co-owner's phone: the "Your key" fingerprint there must match the one shown next to their name on yours. Create a new shared account: each candidate co-owner in the picker shows the fingerprint under their name.

Recovery phrase while recording

Start a screen recording from Control Center, then open Settings → Recovery phrase, and also the phrase screen during onboarding of a new wallet. The words must be replaced by "Hidden while the screen is being recorded or mirrored." Stop the recording: the words come back. The same should hold while mirroring to an external display.

Peers and the network

In Advanced settings, Refresh peer list should still succeed and show the observation date and counts. Set a custom block explorer with a plain http:// address: it must be refused; https:// is accepted. Turn Tor on and wait for Ready: sync, refresh and explorer lookups should behave as before. Leave the app syncing for a longer session (an hour or more) and check that it stays responsive and memory does not climb without bound.

Shared payments

Prepare and approve a shared-savings payment as before, with a saved recipient and with a pasted address. After Finish, if a payment was sent but could not be recorded, the app now says so with the transaction id instead of staying silent; report the exact message if you see it.

Everything else

iPhone, iPad and the Mac build; sending, receiving, labels, backups and import should behave as in 0.6.3.
